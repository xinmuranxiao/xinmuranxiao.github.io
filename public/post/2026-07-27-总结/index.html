async_read

  • 对比async_read_some,async_read这个函数指定读取字节数只有读完才调用回调函数
  • 使用HandleReadHEAD读取同步，再用HandleReadMsg去读
  • 再在start()改为读头的回调函数

索引语法

创建 

create [unique][fulltext] index index_name on taable_name (index_col_name);
  • 创建一个唯一/联合索引

查看 

show index from table_name;
  • 查看表中的所有索引

删除索引 

drop index index_name on table_name;
