RUST

泛型

  • c++的模版
  • 编译器会使用占位符替换
fn 泛型名称<泛型类型>([参数]){}
  • 也可用于结构体
  • 枚举：
enum 结构体名称<T>{
    名称(类型)
}
  • 方法可以
impl<T> 对象<T>{
    fn 方法名([参数])->&T
}
  • 会执行单态化

trait

  • 描述某种类型具有哪些并且可以与其他类型共享的功能

定义

  • 函数将方法签名放一起
trait trait名{
    函数签名;
}
  • 根据功能能实现不同的方法

trait约束

  • 无法为外部类型实现外部trait
  • 要在同意trait

默认实现

  • 直接在trait的签名下使用
trait trait名称{
    fn 函数名称(){
        //实现
    }
}
  • 他还可以调用其他方法

作为参数

  • 用impl trait
fn 函数名(参数名:impl trait名){}
  • 用trait bound
fn 函数名<T:trait名>(参数名:T){
}

where子句

  • 绑定多个bound
fn 函数名<T,U>([参数]){
where
T:trait名+trait名
U:trait名
}

返回类型

  • 必须指定类型

C++

monitorThread.joinable()

monitorThread.joinable() 是 C++ std::thread 的成员函数：返回 true 表示该线程对象当前关联着一个实际可等待的线程；返回 false 表示它是空线程、已经 join() 过，或已经 detach() 过。所以 join() / detach() 之前通常要先检查它，否则对不可 joinable 的线程调用会抛 std::system_error。

if (monitorThread.joinable()) {
monitorThread.join(); // 安全等待线程结束
}

MySQL单独线程巡检 

            int interval = std::max(5, std::min(60, connect_timemax / 3));
            std::this_thread::sleep_for(std::chrono::seconds(interval));

生成一个介于 5 到 60 秒之间的等待间隔，然后让当前线程休眠这么久，常用于重试、轮询或限速：

  • connect_timemax / 3：把某个超时上限除以 3，得到一个“基准间隔”
  • std::min(60, ...)：这个间隔最多 60 秒
  • std::max(5, ...)：同时最少 5 秒 所以 interval 的取值是：
  • 如果 connect_timemax / 3 < 5，取 5
  • 如果 connect_timemax / 3 > 60，取 60
  • 否则取 connect_timemax / 3 本身
int interval = std::max(5, std::min(60, connect_timemax / 3));
std::this_thread::sleep_for(std::chrono::seconds(interval));

注意事项：

  • connect_timemax 必须是整数类型（int/long 等），否则 std::max/min 的模板参数可能推导不一致导致编译错误。
  • connect_timemax / 3 是整数除法，小数部分会被截断。
  • sleep_for 在极少数系统错误情况下会抛 std::system_error，但一般可忽略。
  • 如果你需要“可中断睡眠”（比如收到停止信号立即退出），改用 std::condition_variable::wait_for 更合适。
