网络编程

json序列化（jsoncpp）

  • 将c++对象序列化为json

特点

  • 轻量级，速度快
  • 易于使用
  • 可靠性高
  • 用于前后端通讯，客户端和服务器通讯

使用jsoncpp 

#include <iostream>
#include <json/json.h>
#include <json/value.h>
#include <json/reader.h>
using namespace Json;
using namespace std;

int main()
{
	Json::Value root;
	root["id"] = 1001;
	root["data"] = "hello world";
	string request = root.toStyledString();
	cout << "request is" << request << endl;

	Value root2;
	Reader reader;
	reader.parse(request, root2);
	cout << "msg id is " << root["id"] << endl << "msg is" << root2["data"] << endl;
}

发送端

  • 先求转换后长度
  • 再转换成大端序
  • 再拷贝消息体

接收端

  • 接收长度
  • 再度数据

MySQL

索引

  • 帮助MySQL高效获取数据的数据结（有序）

概述

优点

  • 提高效率，降低IO成本
  • 通过索引列对数据进行排序，降低CPU的消耗

劣势

  • 索引占用空间
  • 降低了更新表的速度

结构

B+Tree

  • 常见索引类型

hash索引

  • 底层通过hash实现，不能实现模糊查询
  • 性能高
  • 采用特定的hash算法，生成新的hash值，然后放入对应的格子
  • hash冲突，则通过链表
  • 效率高
  • Memory引擎
  • InnoDB具有自适应hash功能

R-tree（空间索引）

  • 空间索引是MyISAM引擎的一个特殊索引类型，主要用于地理空间数据类型，通常使用较少

Full-text（全文索引）

  • 建立倒排索引，快速匹配文档的方式

分类

主键索引（primary）

  • 针对表中主键创建的索引
  • 默认自动创建，只有一个

唯一索引（unique）

  • 避免表中字段值重复
  • 可以用多个

常规索引

  • 快速定位特定数据
  • 可以有多个

全文索引（fulltext）

  • 查找文本中的关键字
  • 可以有多个

在InnoDB中

聚集索引（clustered Index）
  • 数据存储与索引放到一块，索引的叶子结点保存行数据
  • 必须有，只有一个
  • 存在主键，默认主键索引
  • 第一个唯一索引作为聚集索引
  • 自动生成有一个影藏的rowid作为聚集索引
二级索引（Secondary Index）
  • 将数据与索引分开存储，索引结构的叶子结点关联对应的主键
  • 可以存在多个
  • 通过回表查询（先通过二级获取主键，再通过聚集索引获取数据）
