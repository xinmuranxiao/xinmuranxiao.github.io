html

基本框架 

<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <meta name="description" content="这里是页面描述，控制在 50-150 字" />
    <meta name="author" content="你的名字" />
    <title>页面标题 - 网站名</title>

    <!-- 社交分享 -->
    <meta property="og:title" content="页面标题" />
    <meta property="og:description" content="页面描述" />

    <!-- 样式和图标 -->
    <link rel="stylesheet" href="style.css" />
    <link rel="icon" href="favicon.ico" />
  </head>
  <body>
    <!-- 用户可见内容 -->
  </body>
</html>
  • 在VS code可以使用!+enter快速填写框架

<!DOCTYPE html>

  • 文档类型声明

<html lang=“zh-CN”>根元素

  • 包裹整个文档
  • lang属性声明页面的主要语言，利于搜索引擎和屏幕阅读器

<head> 头部

  • 存放字符集，标题，样式，脚本引用，SEO描述等
  • 不可见

<body>

  • 存放所有的文本图片、视频、表单、交互等

meta标签

  • 核心标签之一，描述自身元数据

<meta charset=“UTF-8”>

  • 必须放在之前，规定渲染中文的编码

<meta name=“robots” content=“index, follow”> 搜索引擎爬虫指令

  • index / noindex —— 是否索引该页面
  • follow / nofollow —— 是否跟踪页面里的链接
  • noarchive —— 不保存页面快照
  • 组合示例：noindex, nofollow —— 完全不让爬虫处理

Open Graph(社交分享卡片)

  • 当页面被分享到微信、Facebook、Twitter 等平台时，这些标签决定展示效果：
<meta property="og:title" content="页面标题" />
<meta property="og:description" content="页面描述" />
<meta property="og:image" content="https://example.com/cover.jpg" />
<meta property="og:url" content="https://example.com/page" />
<meta property="og:type" content="website" />
  • 注意 og: 系列用的是 property 属性，而不是 name。

http-equiv 模拟 HTTP 响应头 

<!-- 5 秒后跳转到另一个页面（不推荐，影响体验） -->
<meta http-equiv="refresh" content="5; url=https://example.com" />

<!-- 设置兼容模式：让 IE 使用最新引擎渲染 -->
<meta http-equiv="X-UA-Compatible" content="IE=edge" />

<!-- 设置内容类型 -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />

other 

<!-- 主题色（安卓 Chrome 浏览器地址栏颜色） -->
<meta name="theme-color" content="#4285f4" />

<!-- iOS 添加到主屏幕时全屏显示 -->
<meta name="apple-mobile-web-app-capable" content="yes" />

<!-- 站点图标声明（实际上更常用 link 标签） -->
<link rel="icon" href="favicon.ico" type="image/x-icon" />

<header>头部

  • 表示介绍性内容或一组导航辅助内容
  • 可出现在页面顶部，也可用在 <article>、<section> 内部作为区块头部
  • 一个页面可以有多个 <header>
<header>
  <h1>我的博客</h1>
  <p>记录前端学习心得</p>
</header>

<nav> 导航

  • 表示主要导航链接的区块
  • 并非所有链接集合都要用 <nav>，比如页脚里的一排友情链接，如果是次要的可以用普通 <p> 或 <div> 包裹，而不是 <nav>
<nav>
  <ul>
    <li><a href="/">首页</a></li>
    <li><a href="/about">关于</a></li>
    <li><a href="/contact">联系</a></li>
  </ul>
</nav>
  • 一个列表，跳转到/，/关于，/联系

<main> 主题

  • 表示页面的主导内容，整页中只能出现一次
  • 不应包含侧边栏、导航、版权等重复性内容
  • 常用于提升可访问性，屏幕阅读器可直接跳转到该区域
<main>
  <h2>最新文章</h2>
  <!-- 文章列表 -->
</main>

<section> 章节

  • 表示文档中有主题的分组，通常带标题（<h1>~<h6>）
  • 适合把内容按主题切分：如"产品特性"、“团队成员”
  • 与 <div> 的区别：<section> 有语义（有主题），<div> 无语义（纯粹布局）
<section>
  <h2>公司简介</h2>
  <p>我们成立于 2010 年……</p>
</section>

<article> 独立文章

  • 表示可独立分发或复用的内容 典型场景：博客文章、论坛帖子、新闻条目、用户评论、产品卡片
  • 内部往往包含自己的 <header> 和 <footer>
  • 多个 <article> 可嵌套，如博客文章里嵌套用户评论
<article>
  <header>
    <h2>CSS 布局入门</h2>
    <time datetime="2024-01-15">2024年1月15日</time>
  </header>
  <p>本文介绍 Flexbox 与 Grid……</p>
  <footer>作者：张三</footer>
</article>

<aside> 侧边栏

  • 表示与周围内容间接相关的补充信息
  • 典型场景：侧边栏、广告、引文、相关推荐
  • 如果放在<article> 内部，则表示与这篇文章相关的补充内容
<aside>
  <h3>推荐阅读</h3>
  <ul>
    <li><a href="#">HTML 基础</a></li>
    <li><a href="#">CSS 进阶</a></li>
  </ul>
</aside>

底部

  • 表示区块的页脚，包含版权、作者信息、相关链接、联系方式
  • 可以出现在页面底部，也可出现在 、 内部
<footer>
  <p>© 2024 我的博客 版权所有</p>
  <address>联系邮箱：hello@example.com</address>
</footer>

other

  • <figure> 插图/图表容器 图片、代码块、图表，并与其标题（<figcaption>）关联
  • <mark> 标记/高亮 突出显示文本，如搜索结果关键词、强调某段内容
  • <time> 日期/时间 机器可读的日期时间，利于搜索引擎和浏览器识别
  • <address> 联系信息 作者联系方式、组织地址，通常配合 <footer> 使用
  • <summary> 摘要标题 与 <details> 搭配，生成可展开/折叠的交互区域

块级元素 vs 行内元素 vs 行内块元素

块级元素 Block-level

  • 典型标签： div、p、h1~h6、ul、li、section、header、footer 等
  • 独占一行：每个块级元素默认从新行开始
  • 宽度：默认占满父容器整个宽度（width: auto）
  • 高度：由内容撑开，也可显式设置
  • 盒模型：width / height / margin / padding 全部生效
  • 垂直排列：多个块级元素从上到下垂直堆叠
<div>第一个块</div>
<div>第二个块</div>

行内元素 Inline

  • 典型标签： span、a、strong、em、i、b、label、code 等
  • 不独占一行：多个行内元素在同一行内从左到右排列
  • 宽度/高度：不可设置，由内容决定
  • 上下：margin/padding margin-top / margin-bottom 不生效；padding-top / padding-bottom 会生效但不占据布局空间（视觉上会溢出）
  • 左右：margin/padding margin-left/right、padding-left/right 正常生效
  • 垂直对齐：与同行内容基线对齐（可用 vertical-align 调整）
<span>第一</span>
<span>第二</span>
<span>第三</span>

行内块元素 Inline-block

  • 典型标签： 没有天然的行内块标签，通常通过 display: inline-block 将元素变为行内块。
  • 不独占一行：像行内元素一样，多个行内块元素排在同一行
  • 宽度/高度：像块级元素一样，可以设置 width / height
  • margin/padding：四周全部生效（上、下、左、右）
  • 垂直对齐：默认与基线对齐，可用 vertical-align 控制
<style>
  .box { display: inline-block; width: 100px; height: 100px; }
</style>
<span class="box">A</span>
<span class="box">B</span>

三者切换

  • 通过 display 相互切换
/* 块级 → 行内 */
display: inline;

/* 行内 → 块级 */
display: block;

/* 任意元素 → 行内块 */
display: inline-block;
