网络编程

多线程

  • 为每个io_context分配一个线程里

RUST

数据类型

标量和复合类型

  • rust和c++一样是编译型语言
  • 需要在编译时知道他的具体类型
  • 如果类型较多则必须添加类型的标注，不然编译不过
fn main() {
   let guess = "42".parse().expect("not a num");
}
  • 实现了一个编译器无法判定类型

标量类型

整数类型

  • 没有小数部分
  • 占据32位空间
  • u开头为无符号
  • i开头为有符号
  • 有符号范围为2^n-1~2^(n-1)-1
  • 无符号范围：0~2^n-1

isize和usize

  • 由计算机架构决定
  • 64位为u64和i64，32位为u32和i32
  • 多为对某种集合的索引

字面值

  • 除了byte以外，索引数值后面都运行类型后缀
  • 整数默认为i32
  • 调试模式下，溢出程序就会panic，终止，发布模式下会变为一般的从0开始

浮点类型

  • f32(c/c++的float)
  • f64(c/c++的double)
  • f64为默认类型

数值操作

  • 与其他语言一致

布尔类型

  • 单字节

字符类型

  • char类型
  • 占用4字节
  • 使用单引号
  • 是unicode的标量值
  • unicode中没有字符

MySQL

SQL优化2

主键优化

  • 表数据根据主键的顺序组织存放的。这种就是索引组织表(IOT)

页分裂

  • 页可以为任意值，根据主键排列
  • 数据如果过大，则会有行溢出的
  • 如果超出的数据页，再插入，则会开辟一个新空间，在50%的位置以后移入新的空间，这是主键乱序插入的现象

页合并

  • 当删除记录时，会删除索引
  • 当达到阈值，则会开始找靠近页实现页合并

设计原则

  • 尽量降低主键长度
  • 尽量使用顺序插入，尽量选择自增主键
  • 不用uuid，或者其他自然主键
  • 尽量避免对主键的操作

order by优化

  • Using filesort:全表的索引或者扫描全表扫描，读取数据行，然后在排序缓冲区sort buffer中完成排序操作，非直接返回的排序叫filesort
  • Using index:通过有序索引顺序扫描，直接返回有序数据，操作效率高
explain select list_name from table_name order by index_name;
  • 先升序后倒序之类的会有Using filesort

查看缓冲区 

show variables like 'sort_buffer_size';
  • 如果占满，就会使用磁盘，可以适当提高缓冲区

group by分组操作

  • 满足最左前缀法则

limit

  • 数据过大时，查询排序的代价过大
  • 使用覆盖索引加子查询来优化

事件修饰符

  • 调用event.preventDefault()或者event.stopPropagation()，更好的处理
  • 使用v-on处理

.prevent 

<template>
  <h3>事件修饰符</h3>
  <a @click.prevent="clickhandle" href="bilibili.com">哔哩哔哩</a>
</template>

<script>
export default {
  data() {
    return {};
  },
  methods: {
    clickhandle() {
      console.log("click bilbili");
    },
  },
};
</script>
  • 阻止跳转

数组变化的侦测

  • 在被调用是出发相关的更新

.push

  • 添加
<template>
  <button @click="addListHandle">添加一个数据</button>
  <ul>
    <li v-for="(item, index) of names" :key="index">{{ item }}</li>
  </ul>
</template>

<script>
export default {
  data() {
    return {
      names: ["iwen", "xzt", "666"],
    };
  },
  methods: {
    addListHandle() {
      this.names.push("sakura");
    },
  },
};
</script>
  • ui会自动的添加一个sakura的

替换数组

  • 可以重新赋值使得ui变化

.concat

  • 合并 不会引起ui自动更新
<template>
  <button @click="addconHandle">添加一个数据</button>
  <ul>
    <li v-for="(item, index) of names" :key="index">{{ item }}</li>
  </ul>
</template>

<script>
export default {
  data() {
    return {
      names: ["iwen", "xzt", "666"],
    };
  },
  methods: {
    addListHandle() {
      this.names.push("sakura");
    },
    addconHandle() {
      this.names = this.names.concat(["sakura"]);
    },
  },
};
</script>

计算属性

  • 和函数类似
  • 模版中表达式方便
  • 用计算属性来描述复杂逻辑处理
<template>
  <h3>{{ xxx.names }}</h3>
  <p>{{ js }}</p>
</template>

<script>
export default {
  data() {
    return {
      xxx: {
        names: "eeee",
        con: ["qd", "hd"],
      },
    };
  },
  computed: {
    js() {
      return this.xxx.con.length > 0 ? "YES" : "NO";
    },
  },
};
</script>
  • 实现了判断xxx的con是否有数据

计算属性缓存和方法

  • 计算属性基于响应式去渲染，如果没有变化，则渲染一次
  • 方法则会每次都计算
