网络编程

服务器逻辑层的架构设计

不使用逻辑

  • Session层注册一个读事件
  • asio网络层io_context获取事件，再用对应的操作系统注册模型
  • 然后放入回调函数队列
  • 再返回给对端

将处理剥离

  • 将数据投递逻辑队列
  • 逻辑系统获取数据
  • 返回结果

优势

不使用:
  • 减小单线程的阻塞时间，避免无法处理新线程，形成伪阻塞影响并发
  • 多线程下，回调函数后，会减轻队列阻塞压力

tlv

定义消息节点

  • 加入消息id
class MsgNode
{
	friend class Session;
public:
	MsgNode(int max_len)
	{
		_total_len = max_len + HEAD_LEN;
		_cur_len = 0;
		_data = new char[_total_len + 1];
		_data[_total_len] = '\0';
	}
	~MsgNode()
	{
		delete[] _data;
		cout << "Msg is delete." << endl;
	}
	void Clear()
	{
		::memset(_data, 0, _total_len);
		_cur_len = 0;
	}
protected:
	int _cur_len{0};
	int _total_len{0};
	char* _data{nullptr};
};

SendNode::SendNode(const char* msg, short max_len, short msg_id) :MsgNode(max_len+HEAD_TOTAL),_msg_id(msg_id)
{
	short msg_id_host = detail::socket_ops::host_to_network_short(msg_id);
	memcpy(_data, &msg_id_host, HEAD_ID_LEN);

	short max_len_host = detail::socket_ops::host_to_network_short(max_len);
	memcpy(_data + HEAD_ID_LEN, &max_len_host, HEAD_DATA_LEN);
	memcpy(_data + HEAD_TOTAL, msg, max_len);
}

mysql

索引3

创建索引 

create index index_name on table_name (row_name);
  • 能显著提升查询效率

最左前缀法则

  • 联合索引就要最左前缀，从索引的最左列开始，且不跳过索引的列

索引失效

模糊查询失效

  • 模糊索引的左侧不能模糊，不然不使用索引

or连接的条件

  • 必须要查询的两列都得有索引不然设计的索引都不会用到

数据分部影响

  • MySQL评估使用索引比全表扫描慢，则不使用索引

SQL提示

  • 认为提示达到优化操作目的

use index

  • 使用哪个索引
explain select * from tb_user use index(idx_name) where row_name like "%";

ignore index

  • 不使用哪个索引
explain select * from tb_user ignore index(idx_name) where row_name like "%";

force index

  • 必须使用的索引
explain select * from tb_user force index(idx_name) where row_name like "%";

vue3

模版插值 

<template>
  <h3>test</h3>
  <p>{{ msg }}</p>
  <p>{{ hello }}</p>
</template>

<script>
export default {
  data() {
    return {
      msg: "magic",
      hello: "hello world",
    };
  },
};
</script>
  • 如上实现了插入了p3标签"test"和键值对"msg"与"hello"的插入网页
  • 花括号仅支持单一表达式，即一段可以被求值的js代码，（可以通过能否合法的写在return后面，必须要return的结果）（if else不行，因为要单行的）

运算

  • 三目(?:)
  • :键值对
  • {{}}插值

原始html

  • 双花括号将数据插值为纯文本，而非html
  • 想插入html你需要使用v-html指令
<template>
  <h3>test</h3>
  <p v-html="rawhtml"></p>
</template>

<script>
export default {
  data() {
    return {
      rawhtml: `<a href='src/test.html'>testweb</a>`,
    };
  },
};
</script>
  • 如实现了一个跳转test.html的方法
  • PS:test.html的文件源码
<!--test.html的文件源码-->>
<!DOCTYPE html>
<html lang="CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>test html</title>
  </head>
  <body>
    <h1>test</h1>
  </body>
</html>

属性的绑定

  • 双大括号不能再HTML的attributes（属性）中使用，响应式的绑定一个attribute，应使用v-bind
<script>
export default{
  data(){
    return{
      msg:"active"
    }
  }
}
</script>

<template>
    <div v-bind:class="msg">测试</div>
</template>
  • 实现了将msg的值绑定到了标签上
  • 所有的属性都可以使用v-bind:attributes_name实现
  • 如果绑定值为null和undefined，那么该属性将会从渲染的元素上移除

简写 

<div :attributes_name="key"></div>
  • 如上为一种绑定简写的形式

布尔型

  • 根据是否true/false来决定是否应该存在于该元素上
<script>
export default{
  data(){
    return{
      test:true
    }
  }
}
</script>

<template>
    <button :disabled="test">test</button>
</template>
  • 实现了一个不可点击的按钮

动态绑定多个值 

<script>
export default{

      }
    }
  }
}
</script>

<template>
    <div v-bind="obj">测试</div>
</template>
