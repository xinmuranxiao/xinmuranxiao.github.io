线程

post函数

  • boost::asio::post 是线程安全的，你可以在任何线程里调用它，把任务扔回 io_context 的事件循环去排队执行。所以它最常见的用途是——工作线程算完结果后，把任务投递回主事件循环，这样就能安全地操作 socket、更新共享状态，避免自己加一堆锁。注意 post 只负责投递，不会等任务执行完才返回，执行它的线程是那些正在跑 io.run() 的线程。 举个实际例子：
#include <boost/asio.hpp>
#include <thread>
#include <iostream>
#include <chrono>
int main() {
boost::asio::io_context io;
// 两个线程跑事件循环，post 的任务会被它们执行
std::thread th1([&]{ io.run(); });
std::thread th2([&]{ io.run(); });
// 从任意线程跨线程投递任务
std::thread producer([&]{
for (int i = 0; i < 10; ++i) {
boost::asio::post(io, [i]{
std::cout << "task " << i << " on thread "
<< std::this_thread::get_id() << std::endl;
});
std::this_thread::sleep_for(std::chrono::milliseconds(100));
}
});
producer.join();
io.stop();
th1.join();
th2.join();
}
  • 区别再强调一遍：post 一定排队，绝不直接在当前线程执行；而 dispatch 如果当前已经在 io_context 的上下文中，可能会立即调用。所以跨线程投递用 post 更稳，不会搞出递归调用或死锁。
