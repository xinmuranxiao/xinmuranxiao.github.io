08计划

vue3/html/js/css 20天纯前端计划（每天1-2h）

第1天：HTML 文档结构与语义化（1-2h）

  • 文档基本结构（doctype、html、head、body）与 meta 标签 [HTML] → 📝 任务：新建 index.html，手动写出完整骨架
  • 语义化标签（header、nav、main、section、article、aside、footer） [HTML] → 📝 任务：用语义化标签搭建博客文章页
  • 块级元素 vs 行内元素 vs 行内块元素 [HTML] → 📝 任务：列出 10 个标签，验证 display 差异
  • 练习：语义化搭建博客页面骨架 [HTML] → 📝 任务：仿写你博客 post 页的语义化结构

第2天：HTML 表单与媒体（1-2h）

  • 表单元素（input、select、textarea、button）与 label 绑定 [HTML] → 📝 任务：每个 label 用 for 关联对应 input
  • input 类型（text、email、number、checkbox、radio、file、date） [HTML] → 📝 任务：每种类型各放一个并测试提交
  • 表单验证属性（required、pattern、min/max、maxlength） [HTML] → 📝 任务：邮箱格式校验 + 必填验证
  • 练习：完整的注册表单页 [HTML] → 📝 任务：用户名 + 邮箱 + 密码确认 + 提交按钮

第3天：CSS 选择器与盒模型（1-2h）

  • 基础/属性/伪类/伪元素选择器与优先级 [CSS] → 📝 任务：用 5 种选择器给同一元素写样式验证优先级
  • 盒模型（content、padding、border、margin）与 box-sizing [CSS] → 📝 任务：DevTools 查看盒子模型，对比 border-box 差异
  • 单位（px、em、rem、vw、vh、%）与 BFC 解决 margin 塌陷 [CSS] → 📝 任务：用 overflow:hidden 实现 BFC
  • 练习：卡片组件样式 [CSS] → 📝 任务：头像 + 标题 + 描述 + 按钮的卡片

第4天：CSS 定位与 Flex 布局（1-2h）

  • position（static、relative、absolute、fixed、sticky）与 z-index [CSS] → 📝 任务：实现吸顶导航（sticky）+ 悬浮返回按钮（fixed）
  • Flex 容器属性（direction、wrap、justify-content、align-items） [CSS] → 📝 任务：Flex 实现水平垂直居中
  • Flex 项目属性（grow、shrink、basis、order） [CSS] → 📝 任务：3 列等宽卡片 + 某个项目放大
  • 练习：导航栏 + 卡片列表 [CSS] → 📝 任务：制作你博客的导航菜单 + 文章卡片流

第5天：Grid 与响应式设计（1-2h）

  • Grid 容器属性（template-columns/rows、gap、areas） [CSS] → 📝 任务：grid-template-areas 画页面布局
  • Grid 项目属性（column/row 范围、area 命名） [CSS] → 📝 任务：实现跨行跨列网格
  • 媒体查询 + viewport + rem 移动端适配 [CSS] → 📝 任务：在 3 个断点调整布局
  • 练习：响应式九宫格 + 圣杯布局 [CSS] → 📝 任务：手机 2 列、桌面 3 列

第6天：CSS 过渡与动画（1-2h）

  • transition 过渡属性（property、duration、timing-function） [CSS] → 📝 任务：按钮 hover 变色 + 宽度过渡
  • transform 变换（translate、rotate、scale） [CSS] → 📝 任务：卡片悬停上浮 + 旋转图标
  • animation 关键帧动画 [CSS] → 📝 任务：@keyframes 写 loading 转圈
  • 练习：按钮 hover 动效 + 加载动画 [CSS] → 📝 任务：组合 transition + animation 完整演示

第7天：静态页面综合实战（1-2h）

  • 用 HTML+CSS 完成一个完整落地页（导航、Hero、卡片、页脚） [HTML] [CSS] → 📝 任务：仿站或自创主题的完整落地页
  • 响应式适配（桌面/平板/手机三档断点） [CSS] → 📝 任务：三档断点各截图验证
  • 加入过渡与悬浮动效 [CSS] → 📝 任务：导航/卡片/按钮都加交互反馈

第8天：JS 变量、类型与运算符（1-2h）

  • var/let/const 区别与块级作用域 [JS] → 📝 任务：for 循环中用 var/let 对比效果
  • 基本类型（string、number、boolean、null、undefined、symbol、bigint）与引用类型 [JS] → 📝 任务：typeof 每种类型各打印一次
  • 类型转换、== 与 === 区别 [JS] → 📝 任务：列出 5 个 == 与 === 结果不同的例子
  • 练习：类型判断工具函数 [JS] → 📝 任务：写 isString/isNumber/isArray 通用判断

第9天：JS 函数与作用域（1-2h）

  • 函数声明 / 函数表达式 / 箭头函数 [JS] → 📝 任务：3 种写法实现同一个求和函数
  • 作用域链 与 闭包原理及常见应用 [JS] → 📝 任务：闭包实现计数器 + 防抖函数
  • this 指向与 call、apply、bind [JS] → 📝 任务：4 种调用方式打印 this 并解释
  • 练习：实现深浅拷贝 [JS] → 📝 任务：JSON 浅拷贝 + 递归深拷贝（含数组/对象）

第10天：JS 数组、对象与 ES6+（1-2h）

  • 数组方法（map、filter、reduce、find、some、every、forEach） [JS] → 📝 任务：用每种方法处理一组商品数据
  • 解构赋值、展开运算符、模板字符串、可选链 [JS] → 📝 任务：对象/数组解构 + 合并对象
  • 模块化（export/import） [JS] → 📝 任务：拆分 utils.js 导出工具函数
  • 练习：用 reduce 实现数组去重/分组 [JS] → 📝 任务：去重 + 按首字母分组

第11天：DOM 操作与事件（1-2h）

  • 节点查询（querySelector、getElementById、querySelectorAll） [JS] → 📝 任务：3 种方式选中同一元素对比
  • 节点增删改（createElement、appendChild、remove、classList） [JS] → 📝 任务：动态创建 10 个 li 插入 ul
  • 事件流（捕获/冒泡）、事件委托、阻止默认行为 [JS] → 📝 任务：事件委托实现列表删除按钮
  • 练习：JS 动态渲染列表（增删改查） [JS] [HTML] → 📝 任务：输入内容 → 添加 → 点击删除 → 编辑

第12天：异步编程与网络请求（1-2h）

  • Promise 基础（resolve、reject、then、catch、finally） [JS] → 📝 任务：模拟 3 秒延时 Promise
  • async/await 与 try/catch [JS] → 📝 任务：把 Promise 链改写成 async/await
  • fetch 请求封装 与 Promise.all/race [JS] → 📝 任务：封装 get/post 方法 + 超时控制
  • 练习：请求接口渲染列表 + loading/错误处理 [JS] [HTML] → 📝 任务：加载状态 + 错误提示 + 重试按钮

第13天：Vue3 响应式核心（1-2h）

  • ref 与 reactive 的区别与使用场景 [Vue] → 📝 任务：用 ref 存数字/字符串，reactive 存对象
  • computed（getter/setter）与 watch（deep、immediate、监听多个源） [Vue] → 📝 任务：computed 总价 + watch 深度监听购物车
  • Proxy 实现响应式原理（依赖收集、触发更新） [Vue] [JS] → 📝 任务：手写 mini 版 reactive（get/set 拦截）
  • 练习：响应式购物车数字统计 [Vue] → 📝 任务：加减数量 → 总价自动更新

第14天：Vue3 组件基础与生命周期（1-2h）

  • 组件注册（局部/全局）与命名规范 [Vue] → 📝 任务：全局注册 Button，局部注册 Card
  • SFC 单文件组件结构（template / script setup / style） [Vue] [HTML] [JS] → 📝 任务：写一个完整 .vue 组件（含样式）
  • 组合式 API 生命周期（onMounted、onUpdated、onBeforeUnmount） [Vue] → 📝 任务：打印生命周期执行顺序
  • 练习：将页面拆分为 Header/List/Footer 组件 [Vue] [HTML] → 📝 任务：把已有页面拆成 3 个组件并引入

第15天：组件通信（1-2h）

  • props 传值（类型校验、默认值、required） [Vue] → 📝 任务：父组件传对象/数组/函数给子组件
  • emit 自定义事件 与 v-model 语法糖 [Vue] → 📝 任务：子按钮触发父方法 + 自定义 v-model
  • provide/inject 跨层级通信 [Vue] → 📝 任务：祖组件 provide 主题色，孙组件 inject
  • 练习：父子 + 兄弟组件通信案例 [Vue] → 📝 任务：A 输入 → B 显示（通过父中转）

第16天：插槽与组件复用（1-2h）

  • 默认插槽、具名插槽、作用域插槽 [Vue] [HTML] → 📝 任务：Card 组件支持 header/body/footer 三区
  • 组件复用设计思路（Card、Tab、Loading 等） [Vue] [CSS] → 📝 任务：封装可配置的 Tab 切换组件
  • 练习：封装通用 Modal 弹窗组件（带动画、ESC/遮罩关闭、插槽） [Vue] [CSS] [HTML] → 📝 任务：props 控制显示 + 具名插槽 + 动画过渡

第17天：Vue Router 路由（1-2h）

  • 路由配置（hash/history 模式）与嵌套路由 [Vue] → 📝 任务：配置 /posts 嵌套 /posts/:id
  • 动态路由传参（query、params）与 props 接收 [Vue] → 📝 任务：列表页 → 详情页传 id
  • 导航守卫（全局、路由级、组件内）与路由懒加载 + 404 页面 [Vue] → 📝 任务：未登录跳转 /login + 通配 404
  • 练习：多页面导航 + 登录鉴权跳转 [Vue] → 📝 任务：3 个页面 + 守卫拦截完整流程

第18天：Pinia 状态管理（1-2h）

  • setup 风格 store 定义（state、getters、actions） [Vue] → 📝 任务：counter store + doubleCount getter
  • 同步/异步 actions 与组件中使用 [Vue] → 📝 任务：登录 action 模拟请求并存储 token
  • 持久化（pinia-plugin-persistedstate）与模块化拆分 [Vue] → 📝 任务：刷新页面状态不丢失
  • 练习：用户登录状态管理 [Vue] → 📝 任务：登录/登出 + 全局 token 共享

第19天：组合式 API 与自定义 Hook（1-2h）

  • 语法糖深入（顶层变量、defineProps/defineEmits） [Vue] → 📝 任务：不用 options API 重写一个组件
  • 自定义 Hook 设计（useFetch、useCountdown、useTodo） [Vue] [JS] → 📝 任务：写 useCountdown 倒计时 hook
  • 逻辑复用与代码组织规范 [Vue] [JS] → 📝 任务：按功能拆分 hooks 目录结构
  • 练习：封装 useFetch + 用户信息加载 [Vue] [JS] → 📝 任务：useFetch 支持 loading/error/data/重试

第20天：综合实战项目（1-2h）

  • Todo App：增删改查 + 搜索过滤 + 排序 + 分类 [Vue] [JS] [HTML] [CSS] → 📝 任务：完整 CRUD + 状态筛选 Tab
  • 组件拆分：TodoList / TodoItem / TodoInput / FilterBar [Vue] → 📝 任务：每个组件独立文件 + props/emit 通信
  • Vue Router 页面：首页 / 详情 / 关于 + Pinia 状态集成 [Vue] → 📝 任务：TODO 存 store + 路由跳转详情
  • 弹窗确认删除 + Toast 提示交互 [Vue] [CSS] → 📝 任务：删除前弹窗确认 + 操作反馈
  • 打包构建 + 部署到 GitHub Pages / Vercel [Vue] → 📝 任务：npm run build 产出 dist 并上线
