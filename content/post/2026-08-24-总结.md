# HTTP

## 错误码

HTTP 状态码由三位数字组成，第一位数字表示响应的类别，共分为五类。

### 1xx：信息响应

服务器收到请求，正在处理中。

- 100 Continue：客户端应继续发送请求正文。
- 101 Switching Protocols：服务器同意切换协议。
- 102 Processing：服务器已接收并正在处理，但尚无响应（WebDAV）。

### 2xx：成功

请求已成功被服务器接收、理解并接受。

- 200 OK：请求成功，返回正常数据。
- 201 Created：请求成功且服务器创建了新资源。
- 202 Accepted：请求已接受，但处理尚未完成。
- 204 No Content：请求成功，但无返回内容。
- 206 Partial Content：服务器返回了部分内容（用于范围请求）。

### 3xx：重定向

需要客户端进一步操作才能完成请求。

- 301 Moved Permanently：资源永久移动到新 URL。
- 302 Found：资源临时移动，客户端应继续使用原 URL。
- 304 Not Modified：资源未修改，可使用缓存。
- 307 Temporary Redirect：临时重定向，请求方法不得改变。
- 308 Permanent Redirect：永久重定向，请求方法不得改变。

### 4xx：客户端错误

请求包含语法错误或无法完成请求。

- 400 Bad Request：请求语法错误，服务器无法理解。
- 401 Unauthorized：未认证或认证失败。
- 403 Forbidden：服务器拒绝执行，权限不足。
- 404 Not Found：请求的资源不存在。
- 405 Method Not Allowed：请求方法不被允许。
- 408 Request Timeout：请求超时。
- 409 Conflict：请求与服务器当前状态冲突。
- 410 Gone：资源已永久删除。
- 413 Payload Too Large：请求体过大。
- 415 Unsupported Media Type：请求的媒体类型不受支持。
- 429 Too Many Requests：请求频率过高，触发限流。

### 5xx：服务器错误

服务器在处理请求时发生错误。

- 500 Internal Server Error：服务器内部错误，通用兜底错误。
- 501 Not Implemented：服务器不支持请求的功能。
- 502 Bad Gateway：网关或代理收到上游无效响应。
- 503 Service Unavailable：服务暂时不可用（如过载、维护）。
- 504 Gateway Timeout：网关或代理未及时收到上游响应。
- 505 HTTP Version Not Supported：服务器不支持该 HTTP 版本。

### 常见排查思路

- 4xx 优先检查请求参数、请求头、鉴权信息和 URL 是否正确。
- 5xx 优先检查服务端日志、依赖服务状态和资源使用情况。
- 304 可配合缓存策略优化性能，避免重复传输。
- 429 需要实现退避重试或减少请求频率。
