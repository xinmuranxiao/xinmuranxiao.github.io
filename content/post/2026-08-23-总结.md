# RUST

## EXIT_FLAG.load(Ordering::Relaxed)

- 原子地读取全局 `EXIT_FLAG` 的值，`Ordering::Relaxed` 表示只保证读取操作本身的原子性，不建立任何内存顺序保证。

## Mutex VS Atomic

- `Mutex` 适合保护**复杂数据**，比如 `HashMap`、`String`、结构体；它让线程“先拿锁再操作”，保证同一时刻只有一个线程在读写。
- `AtomicBool` 只适合表示**单个标志位**，比如退出标志、开关状态；它用原子指令直接从内存读写，不需要锁。

## unwrap()VS？

- `unwrap()` 是从 `Result<T, E>` 或 `Option<T>` 中取出内部值的方法：有值就返回，是 `Err`/`None` 就直接 `panic!`
- ?`：出错就向上层返回错误，由调用方决定怎么处理，适合错误可恢复的场景

pub fn WaitExit() {
        while !EXIT_FLAG.load(Ordering::Relaxed) {
            std::thread::sleep(std::time::Duration::from_millis(50));
