- [x] 文档基本结构（doctype、html、head、body）与 meta 标签 ` [HTML]` → 📝 任务：新建 index.html，手动写出完整骨架
- [x] 语义化标签（header、nav、main、section、article、aside、footer） ` [HTML]` → 📝 任务：用语义化标签搭建博客文章页

- [x] 练习：语义化搭建博客页面骨架 ` [HTML]` → 📝 任务：仿写你博客 post 页的语义化结构

### 第2天：HTML 表单与媒体（1-2h）

- [x] 表单元素（input、select、textarea、button）与 label 绑定 ` [HTML]` → 📝 任务：每个 label 用 for 关联对应 input
- [x] input 类型（text、email、number、checkbox、radio、file、date） ` [HTML]` → 📝 任务：每种类型各放一个并测试提交

### 第3天：CSS 选择器与盒模型（1-2h）

- [x] 基础/属性/伪类/伪元素选择器与优先级 ` [CSS]` → 📝 任务：用 5 种选择器给同一元素写样式验证优先级

- [ ] 练习：卡片组件样式 ` [CSS]` → 📝 任务：头像 + 标题 + 描述 + 按钮的卡片

- [x] position（static、relative、absolute、fixed、sticky）与 z-index ` [CSS]` → 📝 任务：实现吸顶导航（sticky）+ 悬浮返回按钮（fixed）
